# PM Sprint Status Agent - 45-second voiceover script

| Time | Scene | Voiceover |
|---|---|---|
| 0:00 – 0:07 | Title, six weekly status dots | Every Friday, project managers spend hours turning Jira boards into status reports. This agent does it for them. |
| 0:07 – 0:15 | Step 1 · the data | We built six weeks of synthetic Jira data for a mobile onboarding project: twenty-three issues, three sprints, weekly snapshots. |
| 0:15 – 0:24 | Step 2 · compute the facts | A Python step computes the facts: velocity, blockers, carry-overs, review stalls, scope creep, and a red, amber or green status. |
| 0:24 – 0:33 | Step 3 · PM judgment | Then Claude adds the judgment: what matters, what to do about each risk, and who needs to decide what, by when. |
| 0:33 – 0:41 | The report, scrolling | The result is one report, week by week. This week it flags the November sixth release as at risk. |
| 0:41 – 0:45 | End card | The code and the live report are on GitHub. |

About 115 words, a comfortable pace for 45 seconds.
